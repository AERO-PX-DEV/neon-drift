# Contributing to NEON DRIFT

NEON DRIFT is a cozy cyberpunk flying-car cruise: rain, neon, no combat, no fail states. Ideas that make
the city feel more alive, more atmospheric or more cozy are very welcome.

## Ideas

Open an issue describing the idea (a screenshot or a reference image helps). Good fits: new districts,
weather, city events, Sanctuary activities, radio stations, photo-mode tools, performance wins.

## Code

1. Fork, then `npm install` and `npm run dev` (http://localhost:5173).
2. Keep the look: blue haze, cyan vertical neon with red accents, amber road lights.
3. Keep it running on modest GPUs: instance repeated things, check the fps counter on the High preset.
4. Run `npm test` before opening a pull request, and describe what changed and how you checked it.

## Assets

Only add assets you can share: CC0 preferred, CC-BY with credit. Add every asset to `CREDITS.md`
(author, source link, license). Don't commit music you don't own; `music/` is ignored on purpose.

By contributing you agree your code is released under the MIT license (see `LICENSE`).
